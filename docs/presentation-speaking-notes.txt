Slide 1 — 0:00–1:00
METHOD, first 60 seconds. We built a collaboration platform around HKGAI rather than one long chat. A coordinator receives the goal and creates subtasks for specialists. Each agent owns task files and private experience records. Agents share selected artifacts through the broker, with the exact version recorded, instead of reading another agent’s workspace. A human can join the group or use a private conversation. When a material question or a critical action needs a real decision, the workflow pauses and resumes the same task after the reply. In the examples today, the evidence will show the actual agents, tool calls, files and human interventions.

Slide 2 — 1:00–2:00
METHOD, second 60 seconds. The model proposes structured tool actions. Trusted code checks task ownership, arguments and authorization before the action runs. Generated Python executes in a digest-pinned container without network access, and files move through the artifact broker. The interface exposes tasks, artifacts, pending questions and logs. A tool returning successfully does not prove that the whole goal is correct, so we inspect the required output and its execution evidence. We also changed long-task handling: reaching a selected operating allowance preserves the task and artifacts for an inspected continuation instead of declaring a content failure. Each agent has private experience records, but our bounded memory experiments do not establish a general learning improvement.

REFLECTION, 60 seconds. Our strongest engineering result is that the platform preserves tasks, files and evidence across human questions and operating pauses. The experiments also show why a successful tool call is not a reliable completion metric by itself: we found concrete data-integrity and statistical interpretation mistakes in plausible-looking outputs. Higher operating allowances helped long tasks continue, but they did not replace source selection, independent arithmetic checks or a clear final handoff. We also need to distinguish product capability from classroom readiness. Before the presentation we need a full rehearsal on this Mac, and before the December 19 submission we will finish the outstanding delivery tests and document actual timing, failures and human interventions. We do not claim that the current known-task results establish unseen-task accuracy or a general memory-learning advantage.
